② 本地 NTRIP Caster

「监听端口」是本机对外提供服务的端口，会真实占用本机 2101。中继 / 上传端填的端口是「对端端口」，本机只是出站去连对方，用的是内核临时端口，所以它们可以都用 2101、彼此不冲突。真正会冲突的只有本机已有程序（含上一个没退干净的进程）占着同一个端口。

③ 无线电数传透传（数传电台）

把本机正在转发的同一路 RTCM 数据，额外透传到一个 USB 数传电台（发送端）。 附近无网络的流动站用配套数传电台即可直接接收差分，无需 NTRIP 账号密码。 本功能与本地 Caster 完全独立，可同时开、也可单独开。

需要彻底恢复默认配置？
网页不提供该入口——重置接口无法可靠区分本机与远程请求，容易成为攻击面。请 SSH 登录设备后执行：
sudo systemctl stop 2rtkserver
sudo /opt/2RTKserver/venv/bin/python /opt/2RTKserver/reset_config.py --yes
sudo systemctl start 2rtkserver
该操作会把管理员恢复为 admin / admin 并清空全部连接设置。路径请按实际安装目录调整。
